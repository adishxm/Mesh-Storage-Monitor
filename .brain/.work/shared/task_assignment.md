# Solo Execution

There are no worker or tester folders in this project. The repository owner executes the phases sequentially.

For every phase:
1. inspect the full repository state;
2. read the phase file and relevant contracts;
3. implement one bounded slice;
4. test the slice and its failure paths;
5. update docs and traceability;
6. write a dated report;
7. commit the work;
8. continue only when the phase gate passes.

Use the reports folder as the history of work. Use the shared decision, blocker, assumption, and merge files as the project memory.
